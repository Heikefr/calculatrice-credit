# Calculatrice crédit

https://heikefr.github.io/calculatrice-credit/

Calculette de crédit immobilier hors ligne pour iPhone (PWA).

- Ouvrir le site dans Safari, puis Partager → « Sur l'écran d'accueil ».
- Après une première ouverture avec réseau, l'appli fonctionne sans internet.
- Les données restent sur l'appareil (pensez à l'export dans Réglages).

Mise à jour du site : changer `CACHE` dans `sw.js` (ex. `credit-immo-v2`) pour forcer le rafraîchissement.
